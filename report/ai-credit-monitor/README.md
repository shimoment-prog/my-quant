# AI 信用与融资风险监测

用户于 2026-11-02 授权每天检查，并于 2026-11-04 补充监测口径。每天北京时间 08:30 检查新增公开披露；出现有证据的重要变化时在当前对话报告，无重要变化保持安静。这是定时检查，不是实时监听。此前 A 股盘前报告继续独立运行。

每周五在同一次 08:30 运行中复核趋势，不另建任务：比较约二十个交易日的可比信用数据、最近可比报告期的现金流和融资变化，以及此前预警是否得到验证。没有足够历史就说明，不能编造趋势；周度复核本身不触发重复通知。

## 三条证据线

1. **真实需求、回款与建设现金流**：跟踪 Oracle、CoreWeave，以及 Microsoft、Alphabet、Amazon、Meta、Broadcom 等企业的收入兑现、实际订单与交付、回款和应收款、客户集中度，以及可核实的算力租赁价格和利用率。核实经营现金流、现金购买固定资产支出和自由现金流；关注资本开支持续快于现金流增长，同时出现回款转弱、收入兑现放缓或融资缺口扩大的组合。区分主动优化项目、工程或供电延迟、需求取消及融资被迫停工；单个项目放缓、管理层指引或股价下跌不能直接认定需求崩塌。
2. **信用融资与偿债缓冲**：优先核实同期限 CDS、对应现金债券利差、新发债定价和评级变化；发行计划、已定价、已完成交割和延期或失败分阶段记录。比较保持币种、期限、债务层级及报价口径一致。CDX.IG 用作相对比较；FRED 投资级和高收益债 OAS 仅是整体信用环境代理，不能写成企业 CDS。CDS 前端付款点数不等于年化基点。核实可用现金、债券类证券、股权证券、受限现金、可用授信、未来十二个月实际债务到期及利息负担；关注流动性缓冲持续下降，同时出现融资成本上升、条款收紧或近期到期压力增加。
3. **实际损失与跨主体传导**：核实取消订单、拖延付款、项目被迫暂停、违约展期、抵押资产减值、债务契约触发、担保兑付，以及银行或私人信贷的减值、拨备和损失。沿客户、项目公司、数据中心运营商、供应商和资金提供方核对交易关系与损失承担者。只有可核实的付款、融资或损失证据才能支持压力扩散；普通贷款对冲、发行量增加和衍生品成交量放大不能单独视为信用危机。未找到公开证据不等于风险不存在。

## 关键口径

- 流动性分列现金、债券类证券、股权证券及出售限制，不将全部证券市值视为现金。受限现金不算一般用途资金；若已排除在披露的现金及证券合计之外，不再重复扣减。区分债务账面值、合同本金到期和未来利息，长期总额不能当一年内全部到期。
- 统一基础现金流口径为经营现金流减现金购买固定资产支出，融资租赁本金另列；同时保留公司自定义自由现金流及其差异。非现金租赁新增、尚未支付设备款、未来租约与采购承诺分别记录，不重复扣减或相加。长期承诺按期限和条件拆分，不能直接等同当期资本开支或即时债务。
- 信用支持和残值担保分别记录受益方、触发条件、最大敞口、公允价值负债、抵押物或追偿权及实际支付。名义额、最大敞口、成交量都不等于违约概率或实际损失；担保、租约、出资及采购承诺涉及同一义务时去重。基差正负不能单独认定 2008 年式危机。
- 财务数据标明报告期和公布日，仅在新财报或可信新增披露后更新；季度数字不能当作每日更新。证券投资收益不是 AI 经营现金回报。state.json 的 supplemental_financial_baseline_file 指向历史财务口径补充，应与原基线核对使用，不能当作新财报、重复证据或新发生事件。

## 判断和记录

- 分类使用：观察、风险升温、风险缓解、严重风险、数据不足。这些是定性判断，不是回测模型或崩盘概率。
- 判断风险升温时，尽量取得至少两条独立证据线，例如回款和现金缺口恶化同时伴随融资条款收紧；明确、已核实的违约或重大融资中断可单独构成重要事件。风险缓解也需要证据，数据缺失不能视为正常或风险缓解。
- 主要比较最新一次可比数据、约二十个交易日的变化及上次已通知状态。没有足够历史时不计算虚构趋势。
- 每次保存简短结构化观察至 observations/YYYY-MM-DD.json，并更新 state.json。记录发布时间、行情对应时间、原始链接、口径、证据等级、缺失项、三条信号变化及判断理由；周五另记录趋势复核结果。相同来源的多次转载只算一条证据。
- 首次执行交付一次监测基线。后续仅重要变化、重大事件或整体监测持续无法执行时通知；相同新闻转载、正常财报等待、周末无更新不重复提醒。
