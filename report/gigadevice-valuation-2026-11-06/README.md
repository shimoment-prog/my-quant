# 兆易创新估值与走势核对（2026-11-06）

报价采用A股603986上午收盘243.41元（新浪11:30:00），不是全天收盘。估值采用A股价格乘全部A/H股本703,971,427股的A股等价口径，不是两市场实际分部市值相加。

短期价格低于5/10/20/60/120日均线，238.2元为当日上午已形成低点，不是确定支撑；248—250、260—265元为根据近期价格结构和均线划定的验证区，不是目标价。

其他权益工具公允价值计入OCI的变化不等于利润或经营现金流；利润表金融公允价值收益和扣非口径须分别核对。东财历史总股本字段有回填现值现象，本次不用它重构历史估值。
