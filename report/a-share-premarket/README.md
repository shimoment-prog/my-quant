# A股盘前报告执行记录

报告使用用户客户端北京时间（Asia/Shanghai）的实际日期。执行前同时核对当前日期、触发记录日期、报告日期和来源行情日期。

- 旧触发记录与实际日期不一致时，不将旧日期报告作为当日报告发布；保留旧报告，记录日期差异。
- 用户明确要求补正当日报告时，采集当日所需的新数据，不仅重发旧报告链接。
- 已过09:30时标明“研判补报”，分开盘前已知信息、已发生的开盘/盘中实况和此后的条件判断。不得将盘中走势算作事前预测，也不得将补取报价标成08:45快照。
- 美股使用最近一个已结束的正常交易时段，指数、期货、债券收益率、汇率分别保留交易日期和行情时点。A股昨日行情只取完整历史日线。
- 检查并复盘上一交易日报告；无法验证的数据记录缺失。新报告及其证据不得覆盖其他日期历史。

`YYYY-MM-DD.md` 是报告，`.json` 保存日期、口径、来源、缺失和通知决定；原始材料及请求记录保存于 `evidence/YYYY-MM-DD/`。例：2026-11-17补报保留09:49盘中报价，不改写为08:45盘前数据。
