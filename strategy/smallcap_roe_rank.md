# 小市值＋ROE双因子策略

脚本：`strategy/smallcap_roe_rank.py`，整份复制进聚宽Python3策略编辑器，选择**分钟**回测。

来源：[【量化课堂】多因子策略入门](https://www.joinquant.com/view/community/detail/fd9bf8d85320864d6718ed35e16d4c6a)，以及本项目`test/double_factor_filter_strategy.py`最早克隆版本（Git提交`9d99cb1`）。原文件保持不变。

## 已核实的规则与本版实现

| 规则 | 实现及依据 |
|---|---|
| 股票池 | 上一交易日沪深300成分股；“小市值”指池内相对小，不是全A微盘 |
| 停牌过滤 | 当前未停牌，过去63个交易日完整样本均未停牌 |
| 市值因子 | `valuation.market_cap`总市值，越小越优 |
| ROE因子 | `indicator.roe`原财务指标字段，越大越优；未替换成TTM或扣非ROE |
| 数据时点 | `get_fundamentals(..., date=context.previous_date)`，取当时已公布财报和上一交易日市值，不传`statDate` |
| 缺失值 | 用当期候选池该列的有效均值填充；整列缺失时跳过本轮，保留原计划 |
| 双因子排名 | 市值升序排名＋ROE降序排名，分数越小越优；两个因子等权 |
| 并列处理 | 各因子并列取平均名次，综合同分按股票代码升序；这与原冒泡排序的并列处理可能不同 |
| 持股 | 目标20只；不足20只时每只仍按总资产98%÷20，余款留现金，不集中到少数股票 |
| 调仓 | 回测首日生成计划，此后每15个市场交易日一次；周末不计数，非“每月固定一天” |
| 买卖 | 09:31生成计划，09:32先卖，09:35买，14:50重试；分钟回测 |
| 未成交 | 查询未完成订单防重复委托；只按账户实际持仓判断持股；旧仓未卖出会占名额及仓位预算 |
| 未卖出的落选股 | 后续交易日09:32和14:50继续尝试退出；若新一轮重新入选则按新计划执行 |
| 限制 | 停牌跳过；涨跌停不新买，跌停不尝试卖；检查`closeable_amount`遵守T+1 |

没有额外添加ROE>0、固定市值范围、营收增长、ATR止损或大盘择时。科创板每笔买单预算至少覆盖200股；其他股票至少100股。科创板市价委托设置保护价：买单用当日涨停价作为最高成交边界，卖单用当日跌停价作为最低成交边界；这不保证委托一定成交。持仓市值上涨后可以超过初始98%，98%是调仓下单预算，不是持续强制仓位上限。

最早克隆代码参数为15日/63日/20只；现有旧文件已被用户后续调整为20日/63日/10只。本版采用最早克隆参数，但无法证明这组参数就是原文42倍截图所用参数。原文源码入口本次显示需登录，未绕过访问要求。

原实现两个因子都降序排名，按“市值名次－ROE名次”从大到小选；无并列值时与本版排名和从小到大选择等价。以排名合成不是“先筛最小20只，再从中选ROE最高”，也没有固定ROE阈值。

## 与历史结果的关系

原文图片显示：2005-01-05至2016-05-03、初始100万元、日频；累计收益4258.99%，年化40.94%，最大回撤70.503%。累计收益4258.99%表示赚约42.59倍本金、期末约43.59倍本金。它是作者的历史截图，本版尚未复现。文章当前附带的回测展示2015-01-01至2015-06-01，也不能与42倍图区间混为一谈。

本版修正了原克隆开盘查询当日市值的问题，改用T-1快照；并加入明确的交易时点、交易限制、现金余量和未成交处理。因此即使采用同一区间，结果也可能不同。原文在同一段历史上反复试因子后挑选最佳组合，有样本内选择偏差，需要看2016年之后的表现。

## 回测建议和费用假设

- Python3、分钟频率，先用2015-01-01至2016-05-03验证平台运行，再单独测2017—2020、2021—2023、2024—2026等区间。结束日不得晚于平台已更新的数据。资金可从100万元起步；较少资金可能买不满20只。
- 滑点设置为`PriceRelatedSlippage(0.00246)`。买卖佣金：2009年前0.3%，2009—2010年0.2%，2011—2012年0.1%，2013年起0.03%，最低5元。佣金分段借鉴本地历史克隆，并不表示所有账户实际费率。
- 卖出印花税假设：2023-08-28起0.05%，此前统一0.1%。**未逐段还原2005—2008年历史税制**，因此2005起全周期成本不属于精确历史复刻。买入印花税设为0。滑点和最低手续费也会影响可买手数及收益。
- `indicator.roe`保留原策略字段：查询日可见的最近一期报告数据，不应称作统一年化ROE、TTM ROE或扣非ROE；不同公司最新报告期可能不同。
- 09:35或14:50看见的价格只用于提交委托，成交价由聚宽撮合、滑点、流动性等决定；停牌、跌停或部分成交会导致组合偏离目标。这里只实现回测脚本，不执行真实证券交易。
