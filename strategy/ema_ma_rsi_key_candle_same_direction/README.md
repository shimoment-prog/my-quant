# EMA / SMA / RSI 同向交叉关键K策略

策略标识：`ema_ma_rsi_key_candle_same_direction`。版本：`1.0.0`。记录日期：2026-11-26。

本目录将最新已确认规则独立保存：**双均线先连续同向，再出现有效交叉，从下一根起寻找关键K**。指标为橙色EMA10、白色SMA10、Wilder RSI14；当前标准回测周期为4小时。

保留四种独立退出方式，每种比较交叉前连续同向3～10根，共32个参数组合。当前未指定单一交易组合，默认运行全部32组对照。旧策略目录保留自己的文件与历史配置。

## 指标与参数

| 参数 | 定义 |
| --- | --- |
| 橙色快线 | EMA10，收盘价，权重 `2 / 11`，从输入第一根收盘价初始化 |
| 白色慢线 | SMA10，最近10根收盘价的简单平均 |

| 连续同向根数N | 比较3、4、5、6、7、8、9、10根；交叉当根另检查一次 |
| 关键K的双线方向 | 不额外要求继续同时上升或下降 |
| 额外入场过滤 | 不启用斜率幅度、量比、ADX或回踩触发方式二 |

所有周期都以当前图表的K棒计。四小时图的10表示10根四小时K，14表示14根四小时K的价格变化。

## 触发：连续同向后交叉

设交叉当根为`t`，用户参数为`N`。

- 多单：在`t-N`至`t`的每次变化中，EMA和SMA都严格高于各自上一根；同时本根金叉，即`EMA_t > SMA_t`且`EMA_(t-1) <= SMA_(t-1)`。
- 空单：上述每次变化中，两线都严格低于各自上一根；同时本根死叉，即`EMA_t < SMA_t`且`EMA_(t-1) >= SMA_(t-1)`。
- 一共检查`N+1`次双线变化，使用`N+2`组线值。例：N=3，检查`t-3、t-2、t-1、t`四次变化，使用`t-4`至`t`五组线值。
- 混向、走平或历史不足的交叉当场作废。后来恢复同向也不补启动，必须等新的合格交叉。
- 有效交叉当根只启动等待，**不能同时作为进场关键K**。

底层配置`cross_direction_bars`表示含交叉当根的总变化次数，因此必须等于用户参数`N+1`。

## 关键K与进场

从有效交叉的下一根起，寻找第一根符合下表的关键K，使用该根确认收盘价进场。

| 条件 | 多单 | 空单 |
| --- | --- | --- |
| 均线排列 | EMA > SMA | EMA < SMA |
| K棒阴阳 | 收盘 > 开盘 | 收盘 < 开盘 |
| 完整影线 | 最低价 > max(EMA, SMA) | 最高价 < min(EMA, SMA) |
| RSI | 50 < RSI ≤ 70 | 30 ≤ RSI < 50 |

影线触线也不合格。线值均使用本根收盘确认后的值；这里比较的是本根OHLC与本根最终均线值，不是K内逐笔均线轨迹。

初始止损为关键K当时的橙色EMA，按该币种价格步长四舍五入。多单止损在进场下方，空单在进场上方。初始风险为进场参考价到取整止损的距离。

初始风险须至少一个价格跳动，原1.5R目标须为正且位于盈利一侧。价位无效时继续等待后续关键K。价位有效但数量、最低金额或资金检查拒绝订单时，本次等待被消耗清除。

等待不设固定根数上限。均线相等或排列反向、离开允许开仓窗口时取消等待。同时只持一笔，不加仓、不直接反手；持仓期间的新触发不保留，平仓当根不重新开单。

## 四种退出方式

### 1. 原版1.5R：`rr15`

初始止损保持固定。多单目标为`进场 + 1.5 × 初始风险`，空单目标为`进场 − 1.5 × 初始风险`，再按币种价格步长取整。

### 2. 1.5R后EMA追踪：`trail_ema`

初始阶段只保留原止损，无固定止盈。入场后的K，最高价（多）或最低价（空）触及原1.5R价且未先止损，在该根收盘启用追踪；之后保持启用。

- 多单新止损：`max(旧止损, 进场成交价, 当根EMA取整价)`。
- 空单新止损：`min(旧止损, 进场成交价, 当根EMA取整价)`。
- 每根收盘计算，下一根才生效。止损只收紧、不放宽，不能用收盘后算出的止损回填本根此前高低点。
- 进场价保护只是价格保本，没有覆盖手续费或跳空损失。

### 3. EMA明显变缓收盘平仓：`ema_slow`

保留固定初始止损，不挂EMA移动止损。触及原1.5R且存活后，持续检查每根确认EMA的变化。

定义`d = EMA_t − EMA_(t-1)`、`p = EMA_(t-1) − EMA_(t-2)`；多单`side=1`，空单`side=-1`，令`g = side × d`、`previous_g = side × p`。

同时满足以下条件才在该根收盘全平：

```text
previous_g > 0
0 < g <= 0.5 * previous_g
```

即EMA仍沿持仓方向变化，但本根变化幅度不超过上一根50%。阈值固定50%，等于50%包含；EMA走平和直接反向均不按本方式触发。

### 4. EMA转向收盘平仓：`ema_turn`

同样保留固定初始止损，触及原1.5R且存活后持续检查。满足`g < 0`时按确认收盘价全平：多单EMA下降，空单EMA上升。EMA相等不触发，不额外要求上一根必须同向。

这两个斜率退出分别运行，不组合成“变缓或转向满足任一个就退出”。启用价允许盘中触及，不要求退出时收盘仍在1.5R外，也没有额外的净盈利保护条件。

## 成交顺序、区间与资金

1. 最早在入场后的下一根处理退出。
2. 先执行此前已生效止损的跳空或触价。固定目标同根双触时按止损优先。
3. 仓位仍存活到收盘，才检查斜率信号或更新追踪止损。
4. 斜率信号按实际确认收盘价成交；EMA值只生成信号，不当作该笔成交价。

图上时间标签为K线开盘。例如08:00的四小时K到12:00才收盘，不能使用最终EMA在08:00成交。盘中触价只有所在K区间，无法从四小时OHLC知道具体分钟。

| 设置 | 当前标准值 |
| --- | --- |
| 记账币种、初始本金 | USDT，10000 |
| 每笔目标保证金、杠杆 | 200 USDT，10倍 |
| 每笔目标名义仓位 | 2000 USDT，不复利 |
| 数量 | 目标名义仓位除成交价，再按本币数量步长向下取整 |
| 手续费 | 单边0.05%，进出场分别计费 |
| 滑点 | 0 ticks |
| 合约过滤器 | 每币单独输入tick、数量步长、最低数量和最低名义金额 |

数量取整后实际保证金可能略小于200U。杠杆已通过数量反映，计算盈亏不能再乘10。数量、最低金额或保证金加开仓费检查不合格时拒绝开仓。

价格价位使用Decimal half-up取整，进场收盘参考价保留历史原始精度。回测使用保存的合约过滤器贯穿历史，未重建逐年精度变化。

开仓窗口按确认收盘时间判断，`start <= time_close <= end`，两端包含。输入数据只使用`time_close <= end`的完整K；即使CSV附带未来行情，也须先截断。起点之前或恰好起点至少有200根已完成K作预热。

区间结束不强制平仓。Open单按最后收盘价估值，扣已发生开仓费，尚未发生的平仓费不预扣；Open不计胜率。闭单Win/Loss按双边费用后的净额判断。最大回撤按K收盘权益统计，逐笔累计已实现余额与期末含浮盈权益分别列示。

当前模拟未计永续资金费、标记价触发、强平及真实盘口冲击；确认收盘价成交属于回测假设。

## 运行与记录

`run_backtest.py`为本目录入口，使用Python标准库。输入CSV包含`open_time_ms,open,high,low,close,volume,close_time_ms`，时间为UTC毫秒，并包含预热及整个请求区间。

历史行情CSV、交互图及完整回归依赖的`.archify/`目录为本机回测产物，未随本策略提交。新克隆运行时，请自行提供符合上述格式的真实合约行情CSV；本目录的`references/`保存汇总快照与来源记录。

时间参数建议显式写UTC偏移，且落在四小时收盘边界。示例中的ETH合约精度须替换为目标币种实际快照：

```sh
python3 strategy/ema_ma_rsi_key_candle_same_direction/run_backtest.py \
  --csv /path/to/ETHUSDT-4h.csv \
  --symbol ETHUSDT \
  --start 2021-11-23T00:00:00+08:00 \
  --end 2026-11-23T00:00:00+08:00 \
  --tick-size 0.01 --qty-step 0.001 --min-qty 0.001 --min-notional 20 \
  --output strategy/ema_ma_rsi_key_candle_same_direction/output/eth-4h
```

不指定退出和根数时运行全部32组；指定`--exit-model ema_slow --prior-bars 3`只运行该组合。运行输出保留每笔条件、费用、未平仓状态与权益曲线。

当前前十币种名单是最新回测的研究样本，不是永久交易名单或历史动态换仓信号。后续改规则、参数范围或成本口径时，更新版本并建立新的回测记录，保留本次快照。
